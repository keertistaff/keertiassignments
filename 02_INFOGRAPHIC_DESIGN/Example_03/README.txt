ADOBE ILLUSTRATOR PRACTICAL ASSIGNMENT
=====================================
Category: 02 - Infographic Design
Example: 03 - Water Conservation Awareness

1. ASSIGNMENT TITLE
Global Water Scarcity & Practical Household Conservation Guide.

2. ASSIGNMENT OBJECTIVE
Design an inspiring ecological data infographic highlighting global freshwater scarcity statistics and practical water conservation tips using vector teardrop graphics and clean donut charts.

3. ARTBOARD & SETUP
- Size: A4 Portrait (595.28 x 841.89 pt)
- Color Mode: CMYK / RGB
- Core Stats:
  - 97.5% Salt Water (Oceans)
  - 2.5% Fresh Water (68.7% in Glaciers, 30.1% Groundwater, 1.2% Surface)
- 4 Key Action Tips:
  1. Fix Dripping Faucets (-20 L/day)
  2. Install Low-Flow Aerators (-40% Usage)
  3. Efficient Shower Timers (-50 L/shower)
  4. Rainwater Harvesting (Garden Irrigation)
