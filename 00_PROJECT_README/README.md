- A centralized **`11_ALL_ASSETS_LIBRARY/`** containing reusable fonts, icons, logos, textures, and illustrations.

## 4. SOFTWARE REQUIREMENTS & USAGE INSTRUCTIONS

### Recommended Software
- **Adobe Illustrator CC 2020** (v24.3) or newer (CC 2021, 2022, 2023, 2024).
- **Adobe Acrobat Pro / Reader** for PDF proofing and inspection.
- **Web Browser** (Chrome / Edge / Firefox) for vector SVG previewing.

### How to Open & Edit Assignment Files
1. **Fonts First:** Before opening project files, install the required fonts from `11_ALL_ASSETS_LIBRARY/Fonts/` (select font files, right-click, and choose **Install for all users**).
2. **Opening Project Files:**
   - Double-click `Illustrator_File/Example_XX.ai`.
   - Alternatively, File > Open in Adobe Illustrator.
   - When prompted with font replacement, ensure Montserrat, Poppins, Orbitron, Inter, or Playfair Display are active.
3. **Layer Organization:**
   - All files feature structured layers: `Background`, `Artwork_Asset`, `Brand_Logo`, `Typography`, `Guides_&_Bleed`.
   - Keep individual layers locked while working on specific elements.
4. **Exporting Production Files:**
   - Print PDFs: File > Save As > Adobe PDF (Preset: `[High Quality Print]`, Marks and Bleeds: Check *Use Document Bleed Settings*).
   - Digital Web: File > Export > Export for Screens (Select PNG @ 300 ppi or JPG 100%).
